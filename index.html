Projects

ExplainAlert: Explainable Anomaly Detection for Cloud Servers

M.Tech research project, June 2026. Guide: Dr. Srinivas A H
  • Detection: Isolation Forest on AWS EC2 reached 97.9% accuracy and 100% recall on 239 labeled CloudWatch samples (CPU, network, disk) collected over 20 hours, with anomalies injected using Linux stress tools.
  • Explainability: SHAP gives each anomaly a root-cause explanation with the percentage contribution of each metric.
  • Alerting: An automated pipeline (AWS SES, Telegram Bot API) sends real-time notifications with remediation steps, within the AWS Free Tier.
  • Comparison: Against native CloudWatch anomaly detection, it adds root-cause explanation, contribution analysis and corrective-action suggestions.
